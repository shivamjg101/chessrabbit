BEFORE YOUR FIRST MOVE

Good questions.

Is ChessRabbit really free?

Yes. ChessRabbit is GPL-3.0 open source software. Every feature is free, with no paid plans, subscription checks, or license keys. Donations are optional.

Can I analyze chess games offline?

Yes. After downloading and installing ChessRabbit, local PGN analysis works offline with Stockfish. Online game imports and live opening statistics need an internet connection. Optional engines and datasets need to be downloaded separately.

Is ChessRabbit a chess engine?

ChessRabbit is a chess analysis and training app. It gives you a board, game library, studies, and training tools. Stockfish is the included chess engine that evaluates positions; you can also add Leela Chess Zero or another UCI engine.

Which computers can run it?

The desktop installer supports Windows 10 and Windows 11 on 64-bit Intel or AMD PCs. Start with at least 4 GB RAM and 1 GB free storage. 8 GB RAM and four or more CPU cores are recommended for deeper analysis. There is no packaged macOS or Linux desktop installer; developers can use the documented Docker setup.

Where are my games stored?

Your desktop games, annotations, and analysis results are stored on your computer. Back up the complete local data folder with ChessRabbit closed. The desktop guide explains storage and backups.

Do I need to install Stockfish separately?

No. Stockfish 19 is bundled with the documented Windows release. Leela Chess Zero, neural networks, Syzygy tablebases, and large reference datasets are optional separate downloads.
