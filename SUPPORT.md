# Getting help

ChessRabbit is a free, volunteer-maintained project. There is no paid support, but these are the quickest routes to an answer.

## Start here

- **Installing on Windows:** the [desktop guide](docs/DESKTOP.md) covers installation, data, engines and backups. If Windows warns about the download, read the [Windows security notes](docs/WINDOWS_SECURITY.md).
- **Leela Chess Zero:** follow [install Leela Chess Zero](README.md#leela-chess-zero-install-and-analyse) and its troubleshooting list.
- **Docker or self-hosting:** see [Local setup](docs/LOCAL_SETUP.md).
- **Guides and product facts:** the [ChessRabbit website](https://shivamjg101.github.io/chessrabbit/) has step-by-step guides and a list of supported platforms and limitations.

## Ask a question

Use [GitHub Discussions](https://github.com/shivamjg101/chessrabbit/discussions) for questions, setup help and ideas. Search first: someone may already have hit the same problem.

When asking, include your ChessRabbit version, Windows version, which engine you selected, and what you expected to happen. For desktop problems, **File → Open data folder → `desktop.log`** usually shows the cause. Remove tokens, passwords and private game data before posting logs.

## Report a bug or request a feature

Open an [issue](https://github.com/shivamjg101/chessrabbit/issues/new/choose) with the bug report or feature request template. A bug report with exact steps to reproduce gets fixed much sooner.

## Security problems

Do not open a public issue for a vulnerability. Follow the [security policy](SECURITY.md).
